BlueprintExporter / bug hunt

A programmatic round-trip oracle. Every target Blueprint — whether a committed fixture or any Blueprint in a real project — is exported to JSON, re-imported into a sandbox package, re-exported, and diffed. Any semantic drift between the two exports is a bug in the plugin: serializer, deserializer, or the schema between them.

The oracle loop (per asset)

source fixture /Game/TestBlueprints/BP_NodeZoo
→FBlueprintSerializer
source.json full FExportedBlueprint tree
redirect assetPath → /Game/_Roundtrip/<name>_RT
→FBlueprintImportManager
sandbox BP fresh UBlueprint in /Game/_Roundtrip/
target.json re-serialise the sandbox BP
→scrub GUID noise
normalized pair guids / ids / timestamps / paths zeroed
PASS if structurally identical
↔FBlueprintDiffEngine
FAIL with a structured diff

Three commandlets, one pipeline

GenerateTestBlueprints

Fixture-only · writes /Game/TestBlueprints/

Builds every committed fixture programmatically via FKismetEditorUtilities::CreateBlueprint, populates variables / components / graphs, compiles, saves .uasset. Skips fixtures already on disk unless -Force. Only ever run against BugHunt/TestProject — it pollutes any other project's Content folder.

BlueprintExportRoundtrip

General-purpose · any project

Runs the oracle loop against a -TargetBP= asset path or directory. Works against any project's Blueprints, not just the fixture set — point it at /Game/Characters/BP_Heister in a project with the plugin enabled. Writes source.json, target.json, a structured report.json, and a sandbox BP under /Game/_Roundtrip/ in the target project.

RunBugHunt

Dual-mode · agent entry point

Single agent entry point. Takes either -Area=<name> (fixture catalog — looks up GetAreaCatalog()) or -Path=/Game/... (recurses any subtree via the AssetRegistry, including UWidgetBlueprint / UAnimBlueprint subclasses). Runs each target through the oracle, emits one aggregated report.json with a categorized summary at the top. Supports -Resume for crash-tolerant multi-hour runs against real projects.

Two modes: self-test vs external project

Self-test (fixture catalog)

Run against BugHunt/TestProject. Fixture corpus is deterministic and committed; regressions are obvious in the per-fixture report.json. This is the pre-ship correctness gate for the plugin itself.

-run=RunBugHunt -Area=Roundtrip (14 committed fixtures, same every run)

External project (any /Game/ subtree)

Point RunBugHunt -Path=/Game/... at any project's .uproject with the plugin enabled — enumerates every UBlueprint recursively, runs each through the same oracle, emits one categorized report.json. Use BlueprintExportRoundtrip -TargetBP= instead when you want paired source/target JSONs for a single asset. Caveat: writes /Game/_Roundtrip/ into the target project — don't run against a read-only tree like UE_DOW without a working copy.

-run=RunBugHunt -Path=/Game/Characters/ (recursive; -Resume skips completed entries)

Why the oracle scrubs GUIDs

Without scrub

Re-imported nodes get fresh GUIDs. The diff engine matches nodes by nodeId which embeds the GUID, so every node reads as added-and-removed.

Changes: 6 added, 6 removed, 0 modified (every single fixture) 0/14 passing

With scrub

Both JSONs have volatile fields zeroed before diffing: blueprintGuid, variableGuid, graphGuid, nodeGuid, pinGuid, nodeId, pinId, contentHash, exportTimestamp, assetPath, sourcePackage. Only semantic drift survives.

8/14 passing the remaining 4 are real bugs

Running it

# generate fixtures (idempotent; -Force to regenerate)
UnrealEditor-Cmd.exe BugHunt/TestProject/BugHunt.uproject \
  -run=GenerateTestBlueprints -nullrhi -unattended -nopause

# per-area hunt (catalog mode; see GetAreaCatalog for valid -Area values)
UnrealEditor-Cmd.exe BugHunt/TestProject/BugHunt.uproject \
  -run=RunBugHunt -Area=Roundtrip -nullrhi -unattended -nopause

# external-project sweep (any /Game/ subtree, crash-resumable via -Resume)
# MSYS_NO_PATHCONV=1 keeps git-bash from rewriting /Game/... to a Windows path
MSYS_NO_PATHCONV=1 UnrealEditor-Cmd.exe SomeProject.uproject \
  -run=RunBugHunt -Path=/Game/Characters/ [-Resume] -nullrhi -unattended -nopause

# single-asset deep dive (source.json + target.json side-by-side)
UnrealEditor-Cmd.exe BugHunt/TestProject/BugHunt.uproject \
  -run=BlueprintExportRoundtrip \
  -TargetBP=/Game/TestBlueprints/BP_NodeZoo \
  -OutDir=D:\scratch\rt -nullrhi -unattended -nopause
